## Viewer

**Why this name**
"Image display mode" was rejected because the screen also plays videos, yet the name sounds as if it handles only images.
"Slideshow mode" was rejected because it uses the name of one feature inside the viewer as the name of the whole screen ([the boundary in §3](../terms.md#t-viewer-vs-slideshow)).
